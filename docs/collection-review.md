# Ревью сбора данных и резервирования — 2026-10-11

Проведено ручное ревью входа, cookie/CSRF, границ профилей, OAuth и отмены запросов, очередей SQLite, миграций, интеграций, резервирования и deployment. Автоматический Deep Security Scan недоступен в этой среде и не запускался. `pnpm audit` на текущем lockfile: 0 известных уязвимостей. Это не доказательство отсутствия всех возможных уязвимостей.

## Подтверждённые и исправленные проблемы

- Legacy import пропускал новые таблицы `provider_snapshots` и `collector_state`. Регрессионная проверка сохраняет сырые поля и состояние коллектора при переносе.
- Исходные страницы API Twitch, YouTube и DA частично терялись при нормализации. Теперь сохраняются успешные ответы с параметрами запроса, в том числе поля без текущей аналитики. OAuth-токены и заголовки Authorization не архивируются как данные API.
- DA realtime мог отбрасывать донаты вне активного эфира. Они сохраняются; привязка и суммы конкретного эфира по-прежнему учитывают его время. Неизвестная дата не выдаётся за точную.
- Поздний ответ отменённого HTTP/WS-запроса мог изменить статус подключения. Проверки поколения соединения не допускают продолжения отменённого сбора.
- Облачный бэкап переставал работать при росте архива выше 48 MiB. Добавлен проверяемый формат частей и восстановление больших архивов; расписание сокращено с 12 часов до 15 минут.
- Проверка загрузки не доказывала восстанавливаемость живой облачной копии. Deployment теперь выполняет download, hash, restore и проверку всей физической SQLite.
- Убрана кнопка «Выйти» из общей навигации; API отзыва авторизации сохранён и проверяется тестами.

## Что нельзя считать собранным

API не раскрывают ники всех зрителей видео и точные интервалы их просмотра, скрытые подписки YouTube, пропущенные realtime-события во время отсутствия соединения. Текст go-live уведомления Twitch не предоставляется используемыми API: название и категория собираются, отсутствующий текст не выдумывается.

Нет обещания «все существующие endpoint платформ»: каталог ограничен данными подключённого канала, разрешениями и квотами. Произвольные чужие аккаунты, OAuth/refresh/socket-токены как аналитические данные, editor/guest-star/unban-request/automod отдельные API-каталоги, YouTube плейлисты/обычные комментарии/произвольные Analytics dimensions не собираются этим каталогом. Их подключение требует отдельного покрытия, разрешений и стратегии квот. Все поля уже подключённых страниц и событий сохраняются для будущего анализа.

До обновления сырые ответы, которые ранее не сохранялись, восстановить из будущих опросов нельзя. Новый сбор расширяет историю с момента установки.

## Проверка Supabase

Прямой MCP-доступ к списку проектов в текущей среде вернул пустой список. Независимая проверка настроенного private bucket и полной копии выполняется на сервере через уже настроенный deployment. Она не является аудитом всех RLS-политик и пользователей Supabase Postgres. В Actions выводятся только идентификатор проекта, возраст снимка, hash/restore/integrity и количества строк; содержимое данных и ключи не выводятся.
