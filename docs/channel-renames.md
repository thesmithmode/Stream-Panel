# Переименование каналов

Текущие имена Руслана: Twitch `rlod`, YouTube `rlod_yt`. Прежние имена — `Fullrandomname_twitch` и `Fullrandomname`. Это переименование существующих каналов: постоянные Twitch user ID и YouTube channel ID сохраняются.

## Сбор и исключение владельца

Сборщики, EventSub, чат и история привязаны к ID, а не к никнейму. Менять `twitch.userId`, `youtube.userId`, `youtubeAccountId`, идентификаторы профилей панели или OAuth-приложений не требуется. Повторный вход только из-за переименования не нужен.

В персональных расчётах исключается владелец внутри своего профиля, включая связанные аккаунты Twitch/YouTube. В другом профиле Руслан остаётся зрителем при наличии наблюдения. Добавлять `rlod` или `rlod_yt` в глобальные исключения ботов нельзя: это скроет его активность и в чужом профиле. Агрегатный онлайн от API сохраняется: платформа не позволяет достоверно вычесть из него конкретного человека.

При очередной успешной Twitch OAuth validation (при старте и каждый час) обновляется логин владельца и ссылки на его канал в истории, включая завершённые стримы. Обновляются только ссылки на корень Twitch-канала с тем же account ID в текущем профиле; VOD, clips, другие аккаунты и YouTube-ссылки сохраняются. Время, ID, привязки событий и показатели стримов не меняются. Пустой login из API не используется для обновления ссылок.

Автоматические названия карточек следуют новому имени Twitch-владельца или автора YouTube при следующем наблюдении. Вручную заданное название группы сохраняется. Старые имена остаются aliases для поиска; смена имени не создаёт нового человека и не переписывает исходные события.

YouTube обновляет название и handle в метаданных примерно раз в шесть часов при успешной синхронизации. Ссылки на трансляции имеют вид `watch?v=VIDEO_ID` и не зависят от handle.

## Оставшиеся упоминания старых имён

- `apps/daemon/src/config.ts`: намеренно сохранён старый Twitch-ник в миграции прежнего универсального исключения. Замена его на новый ник сломала бы очистку старых конфигураций.
- `apps/daemon/test/persistence.test.ts`: проверка этой миграции со старым значением из сохранённых настроек.
- `packages/core/test/channel-rename.test.ts`, `apps/daemon/test/channel-rename.test.ts`, `tests/e2e/stream-links.test.mjs`: исходные имена нужны для проверки перехода на новые с теми же ID, aliases, историей и ссылками в браузере.
- `docs/collection-review.md`: историческая запись об удалении прежнего универсального исключения.
- Этот документ описывает соответствие старых и новых имён.

Рабочие фикстуры владельцев и браузерная проверка двух профилей используют `rlod`. Требования в `docs/user-requirements.md` и список готовности описывают исключение по ID, а не по старому имени.

## Проверка

Регрессионные тесты проверяют смену обоих имён без новых ID, исключение владельца и его связанных аккаунтов, учёт в чужом профиле, сохранение aliases, явных названий групп и исходных фактов. Отдельно проверяются обновление завершённых Twitch-ссылок, сохранность VOD и других аккаунтов, откат всей операции при некорректном login, а также применение изменения через DB worker и обновление YouTube-метаданных без повторного OAuth.

После релиза проверить статус подключений, новые события обоих чатов, обнаружение эфира и переход по ссылке из старой истории. Новые ники не являются заменой постоянным ID в серверной конфигурации.
