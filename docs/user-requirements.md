# Требования владельца

Исходные договорённости пересказаны в предыдущей версии этого файла; личная переписка не публикуется. При аудите 2026-10-06 требования сохранены, неподтверждённые технические обещания отделены от желания пользователя.

## Продукт

Локальная система аналитики стрима: учитывать аудиторию как людей, связывая сообщения и донаты с разных сервисов. Владелец делегирует выбор стека. Референс: [Stream Tools](https://b1trat3.ru/products/stream-tools), но по исходным требованиям виджеты и интерактив не входят в v1.

## Границы согласованных требований

Нельзя гарантировать, что два одинаковых донатных имени принадлежат одному человеку: documented donation resource не содержит стабильного ID отправителя. Предложения по имени исполняют пожелание автоматического сопоставления без выдачи гипотезы за факт. Владелец может явно создать правило автопривязки имени; UI маркирует его как правило владельца, не подтверждённый платформой аккаунт.

Сбор не восстанавливает старый Twitch-чат или исторический список участников до установки приложения. Донаты импортируются только из доступной API истории.

За рамками v1: OBS HTML-оверлеи, таймеры, аукцион, розыгрыши, ввод в игру, другие площадки, SaaS, одновременная запись базы с двух ПК. Если нужен полный функциональный клон Stream Tools, сначала меняется PRD: это расширение исходного скоупа, а не скрытая задача MVP.

Документы [PRD](prd.md) и [спецификация](tech-spec.md) содержат принятые инженерные решения, а не дополнительные выдуманные пожелания владельца.
