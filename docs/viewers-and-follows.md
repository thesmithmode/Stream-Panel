# Зрители и подписки

В аналитике каждого профиля из известного счётчика Twitch и YouTube вычитается один зритель, с нижней границей ноль. Коррекция применяется к историческим и будущим замерам один раз на чтении, до суммирования площадок и расчёта средних/пиков. Пропуски остаются неизвестными. Исходные значения API сохраняются в `stream_samples`; миграция 33 сбрасывает только производные кэши.

Максимальный донат на обзоре — один донат за всю историю профиля, включая донаты вне эфиров. Валютные донаты сравниваются по RUB на дату доната; пока нет курса, они не участвуют в рекорде. Исправления, удаления и фильтр ботов учитываются так же, как в сумме донатов. Неизвестная дата не подменяется датой получения.

Именная история Follow Twitch уже доступна: Люди → карточка человека → Подписки на канал → История изменений. Новые подписки поступают через EventSub и опросы. Отписка определяется отсутствием в полном успешном списке Twitch; время — момент обнаружения, а не точная дата отписки. Неполный/неудачный опрос не доказывает отписку. Подписка и последующая отписка между опросами могут не попасть в историю.

YouTube возвращает только доступные публичные подписки. Исчезновение из списка может означать изменение приватности, поэтому панель не объявляет его отпиской. Платные Twitch subscriptions — отдельный тип событий, не Follow.
