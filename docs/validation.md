Это не подтверждение работы живых аккаунтов. [Ранний browser-results.json](browser-results.json) сохранён как исторический ручной smoke; текущий воспроизводимый набор — тесты репозитория.

### Покрытие текущего локального прогона

**69 тестов: PASS, без skipped/todo.** `pnpm check`: Svelte0errors/0warnings, TypeScript и production build PASS. Единый gate включает все собственные runtime-исходники, workers/CLI и браузер; в новом runtime-файле отсутствие coverage означает ошибку.

| Метрика   | Измерено | Требуемый порог                |
| --------- | -------- | ------------------------------ |
| Строки    | 99,97%   | ≥90% суммарно и в каждом файле |
| Ветвления | 91,76%   | ≥90% суммарно                  |
| Функции   | 98,13%   | ≥90% суммарно                  |

Неисполненные ветки остаются в отчёте: например, защитные fallback Icon и часть provider ошибок. Дополнительных исключений собственного кода нет. Проценты — V8/source-map измерение исполнения; они не гарантируют полноту всех комбинаций. [Политика, команды и исключения](testing-strategy.md).

## Синтетическая нагрузка

Отчёт: [benchmark-results.json](benchmark-results.json).10 000 событий и480 полных опросов по1000 identity, WAL/FULL. Измеряется настоящий `StreamStore.recordPoll` и сетка `StreamStore.grid` на480 минут для одного Person. Это storage smoke в одном тестовом процессе; event loop measurement относится к нему, а не к daemon HTTP.

Проверка не является восьмичасовым сбором, Windows benchmark, сетевым тестом или годовым набором данных. Она не доказывает UI p95<500ms и не моделирует точные приходы/уходы зрителей. Временная БД удаляется после измерения.

До оптимизации настоящий путь сетки занимал около202.6ms, запись poll p95 —102.8ms. Повтор после переиспользования statements и одного индексированного запроса на весь диапазон: **сетка1,86ms, poll p95 13,43ms**, все480 наблюдаемых минут сохранены. БД93,31MB, RSS357,36MB в синтетическом процессе. Это локальные измерения, не гарантия на любом ПК.

CI [37544609907](https://github.com/thesmithmode/Stream-Panel/actions/runs/37544609907), commit `b97f84d`: **Ubuntu и Windows PASS**, все69 тестов без skipped/todo/cancelled и coverage gate. Ubuntu:99,97% строк /91,76% ветвлений /98,13% функций; Windows:99,97% /91,92% /98,12%. Проверены также три регрессии смены Twitch account. Это автоматические CI-среды; проверка целевых Win11/Mint, sleep/network и живого эфира остаётся отдельной. Последующий документационный коммит не меняет runtime-код и запускает тот же workflow без skip.

| G2  | EventSub handoff, внезапный обрыв, рестарт посреди эфира, revocation                        | Нет повторных subscriptions при handoff; внезапный gap виден; stream ID сохраняется; восстановление потерянного чата не обещается                                                        |

| G5  | Целевые Win11 x64 и Mint22.1 x64                                                            | Чистая установка, права папки, запуск, sleep/network и реальная запись; Windows ACL проверены                                                                                            |

| G7  | Ошибка диска/прерывание backup, restore в новую папку; будущий cloud                        | Действующая БД сохраняется; восстановленная проверена; remote usage/ключи/restore измерены                                                                                               |
| G8  | Оставшиеся disk/queue faults, lifecycle races и требования хранения Twitch                  | POST schemas, reordered moderation и основные auth/logout races закрыты автоматическими тестами; durable ingest, bounded shutdown, interrupted backup и условия распространения остаются |
