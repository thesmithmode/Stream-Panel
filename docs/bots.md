# Ручные отметки ботов

В правом углу карточки расположен тумблер с тремя положениями: слева «Бот»,
по центру «Неизвестно», справа «Человек». Подписей на экране нет; состояние
отражается цветом. Поддерживаются мышь, касание и стрелки клавиатуры. Отметка
доступна только для Twitch: без связанного YouTube, других площадок,
привязок донатерских ников и донатов. Владелец канала не может быть ботом.
Сервер повторно проверяет эти условия при сохранении и защищает запись
ревизией карточки.

Отметка сохраняется в базе активного профиля и следует за Twitch-аккаунтом
при объединении, разделении и отмене связей. Появление YouTube или донатерской
связи делает её неактивной. Отмена такого объединения восстанавливает
прежнюю отметку. Решения и настройки Руслана и Гульнас независимы.

В «Людях» доступны фильтры «Всех», «Без ботов», «Только ботов». В событиях,
сообщениях и строках списков участников боты отмечаются голубым фоном,
люди — красным. Открытая карточка человека не закрашивается. Каждая подсветка отдельно включается
в настройках профиля. «Человек» можно поставить вручную; наличие YouTube
или DonationAlerts автоматически означает человека даже без донатов.
Ручные отметки «Бот» и «Человек» взаимоисключающие. Цвет определяется
текущими связями, включая историю.

Глобальная галочка «Учитывать ботов» находится рядом с обновлением данных
(на телефоне — в «Ещё»). По умолчанию она выключена. Она меняет расчёт
наблюдаемой аудитории, сообщений и показателей на их основе, включая прошлые
эфиры. Оба режима имеют отдельные кэши. Изменение отметки инвалидирует факты
только тех эфиров, где присутствовал этот человек; неизменившиеся эфиры
сохраняют готовые факты и сокращения истории.

Счётчик зрителей, полученный непосредственно от Twitch/YouTube, сохраняется
как измерение платформы: API не сообщает, какие аккаунты входят в него.
Исключение ботов из наблюдаемого списка чата не является точным пересчётом
числа людей, смотрящих видео. Подписчики платформ также остаются исходным
показателем сервиса.

API: `GET/POST /api/v1/persons/:id/bot`, тело записи `{bot, revision}`;
`POST /api/v1/persons/:id/human`, тело `{human, revision}`;
`GET /api/v1/persons/page?bots=all|humans|bots`. Отчёты принимают
`includeBots=0|1` для явного выбора режима поверх настройки профиля.
